# Web Scraping & Data Extraction Portfolio

This repository contains real-world Python projects demonstrating
my ability to scrape websites, extract data from PDFs, and deliver
clean datasets in CSV and Excel formats.

These projects are built to reflect real client requirements such as:
- Pagination handling
- Data cleaning
- Structured output
- Excel-ready delivery

---

## 📌 Projects Included

### 1️⃣ Price Tracker
Scrapes product pricing data from paginated e-commerce pages and
exports structured CSV files for analysis.

**Skills:** Web scraping, pagination, data normalization

📂 `projects/price_tracker/`

---

### 2️⃣ PDF Invoice Data Extractor
Extracts structured financial data from PDF invoices including:
invoice number, dates, totals, VAT, and customer information.

**Skills:** PDF parsing, regex extraction, data cleaning

📂 `projects/pdf_extractor/`

---

### 3️⃣ Business Lead Generator
Collects lead-style data from directory-style websites and exports
clean CSV files.

**Skills:** Lead scraping, pagination, duplicate handling

📂 `projects/lead_generator/`

---

### 4️⃣ Job Listings Scraper
Scrapes job listings and exports them into both CSV and formatted
Excel (.xlsx) files with filters and clean layout.

**Skills:** Job scraping, Excel automation, structured output

📂 `projects/job_scraper/`
